# myfirstbot

This repository contains example code for a high-frequency trading Expert Advisor (EA) written in MQL5. The EA focuses on BTC scalping and demonstrates techniques such as multi-timeframe trend analysis, adaptive risk control, and layered pending orders.

## Features
- Sample implementation of entry logic using market rhythm scores.
- Adaptive pending order distances based on trend and structure scores.
- Configurable lot sizes for each order layer.

## Getting Started
1. **Prerequisites** – MetaTrader 5 platform with the ability to compile MQL5 source files.
2. **Installation** – Copy the `.mq5` file into your `MQL5/Experts` folder and compile within MetaEditor.
3. **Usage** – Attach the compiled EA to a BTCUSDT chart and adjust input parameters to suit your risk profile.
